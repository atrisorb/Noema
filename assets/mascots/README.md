# NOEMA Mascots

Eight living glyphs, one per agent. Abstract anatomy, not characters. No emoji.

| File | Agent | Silhouette | Accent |
|---|---|---|---|
| cortex.svg | Cortex | Folded cortical ribbon in a lens | Artery |
| axon.svg | Axon | Tapered axon with myelin beads | Nerve |
| thalamus.svg | Thalamus | Relay lantern with two apertures | Nerve |
| synapse.svg | Synapse | Two interlocking arcs with vesicles | Vein |
| soma.svg | Soma | Bone-and-muscle cube with a heartbeat seam | Artery |
| hippocampus.svg | Hippocampus | Seahorse filament with memory ripples | Vein |
| retina.svg | Retina | Iris with photoreceptor spokes | Nerve |
| aesthesis.svg | Aesthesis | Prism splitting one filament | Artery |

Rules: 48x48 viewBox, 3px body stroke, 2.4px trace, currentColor body, one accent, one radial glow. Tested at 24px in the roster and 96px in the sheet. Hover raises the glow; reduced motion removes the transition. Evidence: `docs/evidence/design-mascots.webp`.

Aesthesis is the eighth mascot but is not a runtime agent yet: the asset ships, the roster does not fake an entry.
